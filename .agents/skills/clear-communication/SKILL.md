# Clear communication

**Inputs:** the reader's question, the facts and exact strings that must be
preserved, and what the reader already knows.

## Procedure

- Start with the answer, finding, recommendation or blocker. Then explain.
- Use simple, specific language. Name the actor, action and referent; make
  "it" and "this" unambiguous.
- Explain an essential unfamiliar term at first use in plain words.
- Give a reason, consequence or example where it helps the reader act.
- Remove staged introductions, repeated background and padded closings.
- Keep qualifications, numbers, paths, commands, IDs and status strings exact.
  Do not shorten away a limit or redefine a technical term.
- Prefer one paragraph with a purpose over a list of fragments. Use headings
  and lists when they genuinely help navigation.

## Output

The requested answer or artifact, with the main point easy to find. A receipt
stays a receipt: compact and fixed-field, not an essay.
