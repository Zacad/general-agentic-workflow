## Written contract walkthrough (hypothetical IDs, not live approvals)

Given parent U-1000@r1 with children U-1001@r1 and U-1002@r1, a user checkpoint that names **only U-1001@r1** permits entry into U-1001, not U-1002. If U-1001's acceptance criterion changes, it becomes r2; the old checkpoint does not cover r2, but U-1002's unrelated status is unaffected. An approved D-1000 applying to subtree U-1000 stays in force for U-1002 when a separately approved D-1001 grants an explicit exception for named U-1001. A replacement of D-1000 requires review of its recorded dependent units and the old rationale remains readable. If both children later verify, U-1000 still needs a check of its own acceptance criteria. This is a reasoning walkthrough of the documented contract, not proof that agents obey every transition; the live cases below test observable parts of it.

## Implications

- Compact worker receipts and attempt-specific report paths worked in the completed calls; the orchestrator mostly coordinated from receipts. Investigators and verifiers did not change deliverables in observed attempts. One incorrect baseline path led to a blocked attempt, preserved as evidence rather than rewritten. Prompt-only boundaries remain a trial hypothesis, not enforcement.
- Non-interactive OpenCode rejects `ask` tool permissions without a human response. The `--auto` option was used **only for disposable trials**; it approves tool calls, never workflow scopes. Some OpenCode CLI calls timed out or failed on access to external global instruction files. The documentation now distinguishes this runtime friction from a missing user checkpoint.
- Fresh OpenCode sessions recovered approved revision, relevant attempts, and current state from files, rather than prior conversation. OpenCode CLI glob searches sometimes missed existing dot-directory files; direct reads using the assigned paths succeeded. Stable path handoffs are valuable even when discovery is imperfect.
- The source kit ignores its own disposable `.workflow/`. Do **not** copy that ignore rule into a target workspace that needs to preserve briefs, checkpoints, and decisions. The new-software branch, fresh existing-code U-9005 trial, U-9006 revision trial, and U-9007 scoped-exception trial finished with independent checks and explicit limits; the earlier U-9002 trial remains separately stopped, not verified. A separate-session Pi worker handoff has now been exercised and independently checked with the stated observation limits; automatic Pi subagent delegation was not established.
